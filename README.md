# Week 9 Assignment Practice Problems

Five standalone Java command-line solutions demonstrating object-oriented design,
shared behavior, and optional capabilities.

## Solutions

| Folder | Program | Description |
| --- | --- | --- |
| `MovieTicketCounter` | `MovieTicketCounter` | Calculates seat ticket prices, convenience fees, and the booking total. |
| `ParcelShippingDesk` | `ParcelShippingDesk` | Calculates parcel charges and optional insurance. |
| `CollegeFeeCounter` | `CollegeFeeCounter` | Calculates student tuition, additional fees, and bus fees. |
| `CityCabFareMeter` | `CityCabFareMeter` | Calculates cab fares, minimum fares, and optional night service. |
| `HomeApplianceEnergyReport` | `HomeApplianceEnergyReport` | Calculates appliance energy use, cost, and optional saver mode. |

## Compile and run

Each folder contains its Java source and compiled `.class` files. From the
repository root, compile and run a program with:

```text
javac MovieTicketCounter/MovieTicketCounter.java
java -cp MovieTicketCounter MovieTicketCounter
```
Replace `MovieTicketCounter` with the desired folder and class name. Each
program reads its input from standard input.
